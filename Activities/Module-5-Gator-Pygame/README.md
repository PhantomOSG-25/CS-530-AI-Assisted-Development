# Module 5: Gator Pygame Project

This activity used GitHub Copilot to iteratively build and refine a playable Pygame project.

The project began with a baby alligator and grew through repeated Copilot-assisted changes and testing. Features added during the activity included movement, prey, scoring, growth stages, bite behavior, adult-only human targets, turtles, a wildlife officer, three health points, a 250-point win condition, game-over handling, and restart behavior.

## Artifacts

- `Gator_Game_Clean.zip` - Clean submitted game package containing the final Python source.
- `Gator_Copilot_Chat.json` - Exported Copilot development conversation.
- `requirements.txt` - Pygame version used for the project.

The project demonstrates iterative AI-assisted development, testing, debugging, requirement refinement, and human verification of generated changes.
