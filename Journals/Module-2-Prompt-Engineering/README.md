# Module 2: Prompt Engineering

This folder preserves the surviving AI-tool transcript from the Module 2 prompt-engineering work.

The activity used a Rock, Paper, Scissors programming task to refine prompts progressively. The prompts moved from a general request to increasingly specific constraints, including removing a dictionary, simplifying the control flow, and keeping the implementation beginner-friendly.

The submitted journal discussed prompt engineering, prompt progression, strengths and limitations of AI tools, and the importance of matching prompting techniques to the specific tool and task.
